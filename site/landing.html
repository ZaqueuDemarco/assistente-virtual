Construção

Um arquivo, sem servidor.

O assistente foi desenvolvido com o Claude, da Anthropic, como parceiro de programação: eu defini o que ele precisava fazer, testei no dia a dia e pedi os ajustes. O resultado é uma página HTML com JavaScript puro, que abre no computador, no iPad e no celular. Os dados desta demonstração são gerados por um script, sempre os mesmos, para que qualquer pessoa veja o mesmo painel.

  • DesenvolvimentoFeito com o Claude (Claude Code), a partir de conversas em português
  • InterfaceHTML, CSS e JavaScript, sem framework; tema escuro e layout para iPad e celular
  • GráficosChart.js, com rótulos de valor, séries comparativas e ranking
  • Excel e PDFSheetJS para planilhas; pdf.js para remontar tabelas de PDF pela posição do texto
  • DadosIndexedDB no navegador, backup em arquivo e cópia em nuvem quando aberto pelo Claude
  • Linguagem naturalInterpretador próprio para pedidos em português; o Claude, com ferramentas que consultam a planilha, para os pedidos livres
  • TestesRoteiros automatizados com Playwright, incluindo iPad e uso sem internet
